Notice anything weird? In Epoch 2, you achieved a best Val Loss of 0.9836. So why did the script celebrate 1.0007 as a "NEW BEST"?
Because between Epoch 4 and 5, you switched hardware from the RTX 5080 to the RTX 3060. While the model weights loaded successfully, your Python script's internal variable (usually something like best_val_loss = float('inf')) reset to infinity when you restarted the script.
To fix this in your training script for the future: Make sure you save and load best_val_loss into your .pth dictionary!
code
Python
# When saving:
torch.save({
    'model_state_dict': model.state_dict(),
    'optimizer_state_dict': optimizer.state_dict(),
    'best_val_loss': best_val_loss, # <-- Save this
    ...
}, 'checkpoint.pth')

# When loading:
checkpoint = torch.load('checkpoint.pth')
best_val_loss = checkpoint.get('best_val_loss', float('inf')) # <-- Load this
