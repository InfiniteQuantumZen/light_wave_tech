As described in the licence, this codebase is referred as a piece of art, 
and thus we don't even label or call it software, or at least not a "out of the box" ready.

HOW TO GET STARTED:

DATA STEPS:
The system assumes .mp4 files to be present of some set resolutions; the system
uses and code assumes upscaled and frame interpolated specs that are derived
from Grok Imagine SD format > upscaled 2x the resolution and frame count
via ComfyUI Custom Node; assumed framerate 24 fps which the system plays
approximately 2xSPEED (with some random variation). See all the resolutions 
used in the main file (32-bit_STEREO_EQ__light_wave_tech_v1.1.9.py 
or whatever the revision might be)


SETUP STEPS:

Here are the steps you need to take to make it work if you have the data procured:

1. For music sync you need to run 
/TOOLS/PfreqReact/USE_THIS__32-bit__instrumental_batch_extract_freq_all.py

or additionally port the real-time version of fourier transforms from 
/TOOLS/mini_audio_player/v3_32-bit_pygame_mini_audio_player.py

2.) Edit CONFIG/filepaths.json to match your filestructure.

3.) For config steps you need to run /CONFIG/config_preload_path_names.py 
which is used to generate precalc version of the video files used
by the system; this also precalc files from /DATA/neural_json_batches
used to select the assets. 

4.) If you don't have used /NeuralTrainer to train your own model, you need to
modify the code from the main file (32-bit_STEREO_EQ__light_wave_tech_v1.1.9.py or 
whatever the revision might be) to use random.shuffle instead that matches
the amount of videos you have in your dataset

5.) Edit audio_vars_playlist.py to match your audio files or hardcode them into the main file 
(32-bit_STEREO_EQ__light_wave_tech_v1.1.9.py) or whatever the revision might be.

AND THAT'S PRETTY MUCH IT.
